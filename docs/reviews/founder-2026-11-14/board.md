## Risks more than one member raised
1. **The core moment has never happened.** There is no backend; no session has been generated end to end. Time to first sound and AI cost per session are unknown (all three).
2. **No proof behind the promise.** Invented figures still visible (Version 1 everywhere; "↑12%"/"↑8%" on the About page in v3), and the Upgrade screen sells "more access" rather than an outcome (Offers, Product, Monopoly).
3. **Asks before listening creep back.** The daily check-in on every sign-in, even for a new user with no "yesterday" (Offers, Product).
4. **No distribution.** No channel and no cost per user for the first 100 (Offers, Monopoly).

## Conditions (merged checklist)
- [ ] Launch Version 3, narrowed to one outcome: racing-mind sleepers.
- [ ] Make the core real: real sessions end to end; measure time to first sound and cost per session.
- [ ] Remove every invented figure a user can see (incl. version-history percentages), fix the v3 seams.
- [ ] Daily check-in never on first sign-in, never interrupting; nothing between the first sentence and the first session.
- [ ] Rewrite Upgrade around the outcome (better sleep); test price inside the 30-person study.
- [ ] A guarantee tied to the two-week report, priced once the cost per session is known.
- [ ] Write down the one result the study must hit, and show that later chapters beat the first for the same person.
- [ ] Name a first channel and its cost per user.

## Where they disagree
- Monopoly scores lowest (4): it sees the per-person feedback loop as the only moat and it is not running yet. Product scores highest (6): the experience is clear and well crafted, the risk is focus.
- Product would switch off community, coins and publishing for the study; Monopoly keeps "recreate with credit" as the only seed of a network effect.

## The strongest version the board can see
Not "sessions for how you feel today" in general, but **a sleep programme for people whose mind races at night**: one sentence, one session in under a minute, "how do you feel now?", and a next chapter that measurably beats the first for that same person. Sold as a result (falling asleep faster within two weeks, with a guarantee), proven by the 30-person study before charging. This is narrower than the pitch, on purpose.
