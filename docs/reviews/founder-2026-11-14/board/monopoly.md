# Monopoly lens
Score: 4/10 | Vote: FUND IF

## Version scores

| Version | Score | Why |

| Version 3 | 7 | It collects the most proprietary data: check-ins in the person's own words, an optional journal, an opt-in wearable, a "Why?" on each change. The data is honest and specific to each person, and that is the raw material of the one advantage this business could own. |

## Best first version

Version 3. Through this lens the first users matter as data, not just as revenue: each check-in and journal entry trains the "which element helps which person" loop that no library app has. Version 3 gathers that data without inventing numbers. Showing invented numbers would poison both the data and the trust.

## What is strong

- **A possible proprietary core.** The 2025 Wellness State Graph (~4,000 knowledge points, ~120,000 weighted links) and its feedback loop are the one thing here that could become much better than the alternatives. Calm, Headspace and Insight Timer sell a fixed library. Aurelia's claim is a session that gets more right for *you* every time you use it. If that holds, every user makes the product harder to catch up with.
- **A visible gap in a leader's position.** Insight Timer markets itself as "No AI" and its share of 1–2 star reviews rose from 9% to 23% (2022 to 2025), over questions before listening, a paywall on rewind and streak pop-ups. Version 3 has no streaks, no rankings and tells progress in words. That is a real difference, not just a lower price.
- **A small market is already named.** The planned 30-person study targets one problem: bad sleep to good sleep. "Adults whose racing mind keeps them awake" is small enough to own first.
- **A seed of a network effect.** Published sessions can be recreated with the creator credited. It is weak today, but it is the only part of the product where one user adds value for another.

## What would kill it (the top 3, most dangerous first)

1. **The moat is unproven and it is not running.** There is no backend. The graph is "being reworked". All data is sample data. If personalised generated sessions turn out only a little better than a good library track, this is an incremental product in a crowded, well-funded market, and competition will take the margin.
2. **A copycat in month six.** Calm or Headspace could add "describe how you feel, get a generated session" on top of their existing audiences. Aurelia's only defence is a feedback loop that already holds months of per-person outcomes when they arrive. That loop needs users first, and the brief sets no way to get them.
3. **No distribution.** No marketing channel is set, so it is unknown how the first 100 paying users arrive or what each costs. The cost of the AI per session is also not stated. A generated session could cost much more to serve than a streamed library track, which would cancel out the margin a monopoly is meant to protect.

## The questions I would ask the founder

- What is the secret: what do you know about why people stop using wellness apps that Calm, Headspace and Insight Timer do not?
- Inside the 30-person sleep study, how much better is a generated session than the best free track on Insight Timer, and how will you measure it?
- How do the first 100 sleep users arrive, through which channel, and what does each one cost?
- What does one generated session cost you to serve, and how does that compare with $10 a month?
- After how many check-ins is a user's personal model better than a new competitor's could be? Is that the switching cost?
- Who on the team can rebuild and run the graph and its feedback loop? Team size is not stated.
- Version 3 says "no percentages", yet the session's About page still shows "↑12%" and "↑8%" on version history. Which is the product's real position?

## If FUND IF: the conditions

1. Narrow to one market: launch Version 3 to racing-mind sleepers only, not to "how you feel today" in general.
2. Get the backend and the feedback loop running on real users. Before scaling, show from the study that later chapters do better than the first for the same person, measured in their own check-ins.
3. Bring a named first channel and an estimated cost per user for the first 100, plus the AI cost per session, before any further spending on design.
4. Remove the remaining invented figures from what real users see, so that the data the moat depends on is clean.
