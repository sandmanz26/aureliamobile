## 7. Honesty notes

- Every therapeutic number in the system (uplift, success, chapters, density, velocity) is **his spec's scenario, not measured**. The code labels it so (`costModel.ts` `NumberLabel`, `therapeuticMap.ts` `ValueKind`). B2 must keep that labelling and must not present a new formula as validated.
- The workbooks hold large catalogues: Grand 4 layers ~1,100 types per modality, DOJO ~620 duals, Deeksha 151 needs. Importing them is data work. Making them *causal* is not possible without real outcomes. The admin should present the structure and the assumptions, not learned links (the healing-map test rule is the model for this).
- The marketing AKPs file and the rest of the Deeksha DUAL tab (empty in the export) are still missing.
